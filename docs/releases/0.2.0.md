# EigenTrail 0.2.0

This version adds checked projector stability, weighted window envelopes,
temporal Gaussian calibration and conditional SPD geometry. Rust implements the
calculations and their independent checkers; Python and R expose the checked paths.
See the [premises, outputs and unresolved outcomes](../curve-calibration.md).

Existing history schemas, common-frame behavior and optional witness calls remain
compatible. Stability uses a separate native entry point. Its inclusive geometric
threshold differs from the existing strict lineage-motion threshold. Whole-space
stability provides no directional identification. Undefined SPD quantities retain
their canonical tags; Python convenience geometry reports use `None`.

Window transfer uses weighted absolute time offsets and charges estimation,
mismatch and drift once. Temporal calibration requires known means, joint
Gaussianity, a prescribed dependence envelope and a shared window-family risk
budget. SPD geometry retains the externally supplied eigenvalue floor; reaching
that floor leaves positivity unresolved.

The release reuses accepted conditional tracking mathematics. The recovered
extensions have independent analytical review and software checks; this release
does not claim additional formal coverage for them.

The [release receipt](https://github.com/TrompetteMarine/EigenTrail/releases/tag/v0.2.0)
records qualified artifacts, checksums, platform scope and actual publication
status. Native qualification covers macOS ARM64, CPython 3.14 and R 4.5.1.
Linux binary publication remains held; CRAN compatibility is a separate track.
The v0.1.0 tag and release remain unchanged.
