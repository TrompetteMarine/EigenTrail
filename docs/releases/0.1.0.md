# EigenTrail 0.1.0

Python and R continuous-history array calls accept an optional `witness` with
one candidate PSD covariance matrix per original date. The shared Rust producer
and independent checker verify the entire knot tuple against the original
nodal radii and adjacent operator-norm constraints, with zero widening.
The omitted-witness route retains its previous behavior. A rejected candidate
can remain `Unresolved`; it does not prove infeasibility. Verified existence is
reported as `OriginalAffineWitness`, separately from the unchanged outer query
bounds and unresolved label alternatives.

Python uses NumPy `float64` `(dates, features, features)` arrays and a keyword-only
`witness`. R uses double `(features, features, dates)` arrays and `witness=NULL`.
Both retain the existing common-frame coordinate-diagonal witness restriction.
See the [runnable witness examples](../quickstart.md#supply-an-affine-witness).

The scope is finite deterministic conditional covariance tracking with compatible
observations and fixed externally separated blocks. Numerical checks and named
fixture replays do not establish statistical coverage for real data, identify a
population model, prove compiler/interval-arithmetic refinement, or certify
unrestricted identity through crossings.

Targets are CPython 3.14 with NumPy >=2.3,<3, R >=4.5, Rust 1.99.0, macOS ARM64,
and GNU/Linux x86-64 with Haswell/x86-64-v3 CPU and OS support. macOS wheels require
macOS 14 or later. Linux CPU-specific wheels belong in qualified GitHub assets,
not a generic PyPI Linux wheel route. CRAN's compiler and CPU compatibility gates
are separate from successful supported-platform R builds.

The [GitHub release](https://github.com/TrompetteMarine/EigenTrail/releases/tag/v0.1.0)
records the exact commit/tree, artifact SHA-256 manifest, actual platform checks,
fixture counts and live or pending distribution channels. Private research
inputs are excluded from source packages, release assets and public CI logs.
