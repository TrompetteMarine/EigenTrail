# EigenTrail R 0.2.2

The R source package corrects build cleanup and linking after CRAN's incoming
checks flagged symbols from the bundled Rust standard-library archive in 0.2.1.
Package-owned Rust build outputs are removed after successful linking. GNU/Linux
linking limits archive exports and discards unused sections.

Numerical calculations, checked JSON schemas, public interfaces, sampling
premises and unresolved outcomes are unchanged. Rust panic unwinding and worker
error handling are preserved. This release retains R 0.2.1's baseline x86-64
support and Cargo/rustc 1.85.1 minimum.

Install R from the named source asset and verify its checksums as described in
the [R installation guide](../r-installation.md). The release receipt records the
qualification results and actual publication status; CRAN acceptance is a
separate review decision.

Current source manifests use version 0.2.2. Python remains published on PyPI as
0.2.0; its pinned installation commands, qualified artifacts and held Linux
binary publication are unchanged.
